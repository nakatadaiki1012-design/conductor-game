# sounds2/

VS Chamber Orchestra 2 Community Edition（Versilian Studios / Sam Gossner ほか, CC0 1.0）
https://github.com/sgossner/VSCO-2-CE

ゲーム用に、使う音だけを選んで、先頭の無音を切り、音量をそろえ、長さを短くして mp3（モノラル 64kbps）にしたもの。
ファイル名は「音名（中央のド = C4）_p（やわらかく弾いた録音）または _f（強く弾いた録音）」。

- vln_sus / vln_spic: バイオリン・セクション（のばす / 短く）
- vlc_sus / vlc_spic / vlc_pizz: チェロ・セクション（のばす / 短く / ピチカート）
- cb_sus: コントラバス
- hn_sus / hn_stac: ホルン、tp_sus / tp_stac: トランペット
- bsn_sus / bsn_stac: ファゴット、ob_vib: オーボエ、fl_sus / fl_stac: フルート
